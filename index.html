Master Q&A Encyclopedia

Detailed technical answers, architecture explanations, and user guides from our knowledge base.

📌 Part 1: General Overview & Architecture
Q1: What is Unlockt and why is it needed? +
Unlockt is an open-source, local-first Chromium extension and Node.js web suite. Instagram's native "Saved" section offers no text search, no carousel slide breakdown, no bulk download, and no offline backup. If a creator deletes a post, your bookmark disappears. Unlockt archives everything locally so you own your data forever.
Q2: Who created Unlockt and what is its license? +
Unlockt was developed by Mahmoud Madi (Digital Marketing & IT Specialist), supported by Premier Tech (For Integrated Solutions) and VOXO AI (AI & Media Agency). It is released under the permissive MIT License (100% Free & Open Source).
Q3: How does Unlockt work without requiring my Instagram password? +
Unlockt operates as a Manifest V3 extension inside your existing authenticated browser session. It reads Instagram's internal GraphQL endpoints using the secure session cookies already stored in your browser. You never enter or transmit your password.
Q4: Can Unlockt sync more than 10,000 saved posts? +
Yes. Unlockt utilizes cursor-based GraphQL pagination with state checkpointing. It can easily crawl through 10,000+ saves without crashing or leaking memory.
🎨 Part 2: Carousel Studio & Collage Maker
Q5: How does Unlockt extract individual carousel slides? +
Unlockt's extractor inspects Instagram's `carousel_media` node arrays, extracting each individual child slide (photos and videos) with its highest resolution CDN URL, aspect ratio, and position index.
Q6: How does the HTML5 Canvas Photo Collage Generator work? +
The studio dynamically loads extracted carousel images onto an off-screen HTML5 Canvas. Users can choose layouts like 2x1 (Side-by-Side), 2x2 (Square Grid), 3x3 (Matrix), or 5x2 (Panoramic Moodboard) with custom gap widths and white borders, exporting in high-DPI PNG format.
Q7: Can I download an entire carousel as a single ZIP archive? +
Yes. With JSZip integration on the frontend, clicking "Download All Slides" bundles every full-resolution photo and video from that post into a neatly named `.zip` archive on your machine.
🎬 Part 3: Reels Inspector & Video Streaming
Q8: How does Unlockt stream saved Reels without lagging? +
The backend Express server implements native **HTTP 206 Partial Content** byte-range streaming. This allows instant timeline scrubbing, quick seeking, and smooth playback of large 1080x1920 MP4 files without pre-buffering the entire file.
Q9: Does Unlockt extract audio track metadata and music titles? +
Yes. Unlockt captures the audio artist name, track title, audio ID, and whether the audio is original or licensed music. You can search your vault specifically for posts using specific sounds or songs.
🔍 Part 4: AI Semantic Search & Indexing
Q10: How fast is the search engine across thousands of saved items? +
The frontend search executes in sub-millisecond speeds using indexed in-memory flat JSON matching across post captions, creator usernames, full names, hashtags, collection names, and custom tags.
Q11: Can I filter by post type (Reels vs Photos vs Carousels)? +
Yes. The top filter bar lets you instantly isolate Reels (Videos), Multi-slide Carousels, Single Photos, or items with Audio.
🛡️ Part 5: Privacy, Security & Anti-Ban Safeguards
Q12: How does Unlockt protect my account from getting banned by Instagram? +
Unlockt employs randomized human-like jitter delays (e.g., 800ms - 2200ms) between pagination cursor requests, automatically honors HTTP 429 rate limit backoff headers, and avoids burst scraping.
Q13: Is any telemetry or data sent to external servers? +
Zero. Unlockt contains no analytics, no Google Analytics, no telemetry trackers, and no external advertising scripts. It functions 100% offline on `localhost`.
Q14: How is the media proxy server secured against SSRF? +
The Express backend validates all incoming media URLs through a strict domain whitelist (`*.cdninstagram.com`, `*.fbcdn.net`), blocking internal loopback IPs (`127.0.0.1`, `localhost`, `169.254.169.254`) and preventing Server-Side Request Forgery.
📈 Part 6: Creator Intelligence & Ad Swipe Files
Q15: How can digital marketers use Unlockt as an Ad Swipe File? +
Marketers can save high-performing competitor ads and creatives on Instagram, then use Unlockt to bulk archive them, tag them by hook type or copywriting angle, and export analytics on top creators.
Q16: How do UI/UX designers and art directors benefit from Unlockt? +
Designers can extract high-res visual references from carousels, build moodboards in the Canvas studio, and export uncompressed graphics for Figma and presentation decks.
⚙️ Part 7: Developer APIs & Setup
Q17: How do I install and run Unlockt locally? +
1. Clone the repository: `git clone https://github.com/mahmoud-madi/unlockt-instagram-saved-chrome-extension.git`
2. Install dependencies: `npm install`
3. Start backend: `npm start` (runs on `http://localhost:3000`)
4. Load `extension/` directory into `chrome://extensions` via "Load unpacked".
Q18: What REST API endpoints does the backend expose? +
- `GET /api/saved`: Fetch all saved posts JSON
- `POST /api/save`: Sync new/updated posts
- `GET /api/proxy/media`: Secure SSRF-hardened image proxy
- `GET /api/proxy/video`: HTTP 206 partial streaming video proxy
- `GET /api/export`: Download full backup JSON/CSV
