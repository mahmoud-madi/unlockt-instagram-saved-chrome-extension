STEP 1

Install yt-dlp (One-time setup)

If you don't have yt-dlp installed on your computer yet, run this in your terminal or Command Prompt:

pip install yt-dlp
STEP 2

Instagram Login / Cookies (Recommended)

To avoid rate limits and download in maximum 1080p quality, yt-dlp can use your active browser session directly with --cookies-from-browser chrome or an exported cookies.txt file in your folder.

STEP 3

Run Command or Download Scripts

You can copy the ready-to-run terminal command below, or download the pre-configured .bat and .txt batch files directly.

yt-dlp --cookies cookies.txt -f bestvideo+bestaudio --merge-output-format mp4 ...
