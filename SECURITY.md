# 🔒 Security & Privacy Policy

## 🛡️ Privacy Guarantee: 100% Local-First Architecture

**Unlockt** is built from the ground up with a strict **local-first privacy model**:

1. **Zero External Telemetry**: Unlockt does NOT connect to external analytics, tracking servers, or remote third-party databases.
2. **Zero Credential Transmission**: Unlockt operates entirely within your active browser session sandbox. You never input your Instagram password into our software.
3. **Local Machine Storage**: All saved content metadata, thumbnails, downloaded reels, and collage exports are stored strictly on your local disk (`data/`, `thumbnails/`, `videos/`).

---

## ⚠️ Safe Operation & Rate-Limiting

* **Anti-Detection Design**: The synchronization engine implements humanized, randomized jitter delays (1.2s – 2.8s) between pagination requests.
* **Safe Sync Modes**: We recommend utilizing the **Quick Sync New** mode for routine updates, which stops immediately when it reaches your last synced post.

---

## 🐛 Reporting a Vulnerability

If you discover a security issue or vulnerability in Unlockt:
1. Please do **NOT** open a public issue on GitHub.
2. Reach out directly to **Mahmoud Madi** via GitHub profile or email.
3. Provide detailed steps to reproduce the vulnerability.

We will review and address valid security reports promptly.
